# VRMA Studio

Desktop editor for VRM Animation (`.vrma`) files — open an animation, watch it on a
VRM avatar, cut/trim/merge on a timeline, export a valid `.vrma`. No Blender
required. See [CLAUDE.md](./CLAUDE.md) for the full project plan and
[docs/format-notes.md](./docs/format-notes.md) for format implementation notes.

## Stack

Tauri v2 · React + TypeScript + Vite · Three.js + @pixiv/three-vrm · Zustand ·
Tailwind CSS · Vitest

## Development

```sh
npm install
npm run dev         # web preview (no Rust needed)
npm run tauri dev   # desktop shell (requires Rust: https://rustup.rs)

npm test            # regenerates test fixtures, runs Vitest
npm run typecheck   # strict TS check
```

## Layout

- `src/core/` — pure TypeScript VRMA engine (parser, writer, operations). No UI
  dependencies; fully unit-tested. Start here: `src/core/vrma/glb.ts` holds all
  binary buffer math.
- `src/app|viewport|timeline|panels/` — React UI (Phase 1 steps 2–5).
- `src-tauri/` — Rust shell (file dialogs, fs).
- `tests/` — Vitest suites; `tests/fixtures/` holds `.vrma` fixtures generated by
  `scripts/make-minimal-fixture.mjs`.
